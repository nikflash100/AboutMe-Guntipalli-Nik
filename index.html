Profile

I'm a seventh-grade student in Minnesota and a developer working mostly in Python, machine learning, and the OpenAI API. Most of what I build points at the same problem: learning is slow when nobody can tell you which specific thing you're missing, so I write software that narrows that down.

I've shipped an adaptive diagnostic app, trained classifiers on student outcome data, and written a parser that turned three and a half thousand archived quizbowl questions into a practice engine. I hold three Python Institute certifications and study accelerated math through UMTYMP at the University of Minnesota.

Outside of code I compete in quizbowl, chess, and Destination Imagination, where my team won the Minnesota state championship in the Middle School Science Division in 2026. I'm aiming at a career in software engineering and machine learning, and everything on this page is a step toward it.

Projects

Signal

K–12 adaptive diagnostic learning app

Signal finds the one topic a student is weakest in. It opens with a 16-question breadth screen, then runs a staircase algorithm and a re-check cycle to narrow the result, coordinating five separate model calls along the way. I built it to survive bad conditions: a 40-question offline fallback bank, state that persists through a force-close, streak tracking, and grade-band routing.

Thunkable · OpenAI gpt-4o-mini · Presented at the Spark Civics Civic Innovation Showcase

SuccessForecast

Machine-learning student outcome predictor

A logistic regression classifier trained to predict pass/fail outcomes, reaching 85.6% accuracy and 0.92 ROC-AUC. I also applied K-Means clustering to the performance data to surface distinct student archetypes, and presented the results at demo day with a full notebook and an eleven-slide deck.

Python · scikit-learn · pandas · matplotlib

Buzzer Station

Quizbowl practice web app

I wrote a parser that structured 3,531 questions from public packet archives — 1,885 tossups and 1,646 bonuses — into a usable question bank. On top of it sits a practice engine with word-by-word delivery, power markers, spacebar buzz-in, automatic answer grading, per-category scoring, and a mode that drills the questions you missed.

HTML · CSS · JavaScript
